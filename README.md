# OnlineLibrary — онлайн-библиотека

C# (.NET 8, ASP.NET Core MVC + Entity Framework Core + SQLite). Проект переделан из CollegeManagement,
структура папок сохранена: Controllers, Models, Services, Views, Data, wwwroot, Program.cs.

## Запуск

    dotnet run            # консольное меню «УПРАВЛЕНИЕ БИБЛИОТЕКОЙ»
    dotnet run -- web     # сайт (в Visual Studio — профиль "Web", http://localhost:5080)

База `library.db` создаётся и заполняется тестовыми данными при первом запуске
(если запускали старый проект — это новая, отдельная база).

Тестовые входы на сайте:

- администратор: `admin` / `12345`
- читатель: `aidana@library.kz` / `123456`

## Что умеет сайт

- **Каталог книг** с поиском (название, автор, год, описание) и фильтром «Только аудиокниги».
- **Описание книги** — отдельный блок на странице книги.
- **Обложка книги** — загружается как фото в «аватарку» книги (форма добавления/редактирования, предпросмотр сразу при выборе файла; JPG, PNG, WEBP, GIF до 5 МБ). Без обложки показывается заглушка.
- **Аудиокнига с YouTube** — в форме книги вставляется ссылка (watch?v=…, youtu.be/…, /embed/…, /shorts/…), на странице книги появляется встроенный плеер.
- **Регистрация и личный кабинет читателя**: ФИО, дата рождения (выбор через календарь), место учёбы или работы (выбор из списка с фильтром по типу и поиском по названию; если нет в списке — можно ввести своё), ИИН (12 цифр), почта, номер телефона, пол (мужской / женский). Данные можно редактировать.
- В кабинете: книги на руках, срок возврата, кнопка «Вернуть», история.
- Читатель сам берёт книгу кнопкой «Взять книгу» (срок 14 дней, не более 5 книг на руках).
- **Администратор**: добавление и редактирование книг, список читателей (поиск и фильтр по месту учёбы/работы), выдача и приём книг, статистика.

## Консольное меню

1. Добавить книгу
2. Показать все книги
3. Найти книгу
4. Добавить читателя
5. Показать читателей
6. Выдать книгу
7. Вернуть книгу
8. Статистика библиотеки
0. Выход

Читатель, добавленный из консоли, не имеет учётной записи для входа на сайт — для входа нужна регистрация на сайте.

## Структура

- `Models/` — Person (базовый класс), Reader, Book, Loan, Organization, User, Gender, модели форм
- `Data/LibraryDbContext.cs` — контекст EF Core, создание БД и тестовые данные
- `Services/` — BookService, ReaderService, LoanService, ReportManager, CoverStorage (загрузка обложек), ConsoleMenu
- `Controllers/`, `Views/` — веб-часть (MVC)
- `wwwroot/` — css, js, images; загруженные обложки лежат в `wwwroot/uploads/covers/`
